## The rules

| Rule | Massachusetts | Source |
|---|---|---|
| Weekly minimum | At least 3 work search activities each week | S1, S2 |
| Different days | Not required. The 3 activities can be on the same day. | S3 |
| Benefit week | Sunday through Saturday. Week ending = Saturday. | S2 |
| Where you report | Online at unemployment.mass.gov/claimants, or by phone (TeleCert). The user does this themselves. | S1 |
| Record keeping | Keep a written record of each activity (type and date). Keep proof of work search for one year after you stop requesting benefits. | S1, S4 |
| Proof | DUA may ask for documents such as emails with employers, application receipts, job postings, job fair announcements. | S2 |

## Fields (DUA Work Search Log, S2)

Output the weekly log in this order. Sheet column in brackets.

1. Date [A]
2. Position [H]
3. Pay rate [M]
4. Employer name and address [E + N]
5. Job ID or person contacted [F, or the employer's posting ID if the user gave one]
6. Contact email, website, or phone [O]
7. Result [I]

Header line for each week: "Week starting Sunday [date] through Saturday [date]."

Note: S2 says people who file online don't need to use the paper form, and can enter activities in the online system. The log is still useful to copy from and as the written record.

## Does it count? (sets "Counts for unemployment")

DUA's lists are examples and say "not limited to," so a blank here doesn't mean an activity doesn't count. It means this file can't back it up.

| Activity type | Counts | Why |
|---|---|---|
| Applied | Yes | S1 lists submitting an application, resume, or letter of interest through an employer or a job website. |
| Interview | Yes | S1 lists interviewing with potential employers in person, by phone, or online. |
| Job fair | Yes | S1 lists attending job fairs and networking events. |
| Networking contact | Yes | S4 lists networking with colleagues or friends. S1 lists networking events. |
| Informational interview | Yes | S4 lists networking with colleagues or friends. |
| Outreach message | Yes | S1 lists a letter of interest sent through an employer. S4 lists networking with colleagues or friends. |
| Reviewed job posting | Yes | S4 lists reviewing job listings on the internet as an example. **Older source:** S1 (the current page) doesn't repeat this example. Recheck at each review. |
| Workshop or training | Yes, only if it was an employment workshop | S1 lists employment workshops. Other training: blank. |
| Other | Blank | Unless it clearly matches an S1 example (for example, registering with a private employment agency or placement service, S1). |
