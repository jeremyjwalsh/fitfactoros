# Want to go further?

FitFactorOS runs on Claude. If you'd like to understand the pieces it uses, or get more out of Claude in general, these free official Anthropic pages are good places to start.

| Start here | What you'll learn |
|---|---|
| [Claude 101](https://anthropic.skilljar.com/claude-101) | A free beginner course on using Claude for everyday work. You'll need to make a free course account. |
| [Anthropic Academy](https://www.anthropic.com/learn) | Anthropic's full list of free courses, from beginner to developer. |
| [Projects](https://support.claude.com/en/articles/9519177) | How Projects work. Your FitFactorOS Project keeps your instructions and files together in one place. |
| [Skills](https://support.claude.com/en/articles/12512180-using-skills-in-claude) | How Skills work. Each FitFactorOS step (intake, research, activity log, dashboard, morning email) is a skill. |
| [Scheduled tasks](https://support.claude.com/en/articles/13854387-schedule-recurring-tasks-in-cowork) | How scheduled tasks work. This is what runs the optional morning email each weekday. The page may use an older product name. |

These links were checked on October 15, 2026. Anthropic moves pages from time to time, so if one doesn't open, search the [Claude Help Center](https://support.claude.com) for the topic.

FitFactorOS isn't made or endorsed by Anthropic.
